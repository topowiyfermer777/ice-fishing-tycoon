# Ледяная Рыбалка (Ice Fishing Tycoon)

Казуальная 3D-игра в жанре **Idle Tycoon / Arcade Management**, разработанная на игровом движке **Godot Engine 4.7.2** (`Forward+`, `GDScript`) с использованием стилизованных 3D-моделей из **Blender**.

## Видео игрового процесса

Демонстрация геймплея в оригинальном качестве (136 МБ) прикреплена к релизу:
- [Смотреть / скачать видео в GitHub Releases (v1.0-demo)](https://github.com/topowiyfermer777/ice-fishing-tycoon/releases/tag/v1.0-demo)

## Основные особенности

- **Игровой цикл (Core Loop):** добыча обычных и гигантских льдин с замороженным тунцом на реке → переноска рыбы Шеф-повару → пошаговая нарезка 5-сегментной туши на стейки → выдача трём очередям клиентов → сбор растущей стопки денег за спину.
- **Прогрессия и автоматизация:**
  - **Бревенчатая дамба ($100)** — перегораживает реку перед водопадом, удерживая льдины.
  - **Наём рабочих ($200–$500, до 4 чел.)** — автономные добытчики `Worker_Kenny`, которые сами добывают рыбу.
  - **Конвейерная линия ($200)** — полностью автоматизирует доставку рыбы шеф-повару и подачу стейков на прилавок.
- **Графика и шейдеры:** выборочная чёрная обводка (`Inverted Hull` со сглаживанием нормалей в `CUSTOM0`), преломляющий лёд с 3D-трещинами Вороного, анимированные шейдеры реки, двухъярусного водопада с частицами пены `GPUParticles3D`, нижнего озера и снежного покрова.
- **Интерфейс и пасхалка:** минималистичный HUD, живое 3D-меню поверх реки с настоящей паузой, возможностью разбивать льдины кликом и пасхалкой с героями «Южного Парка» на берегу при разбивании 10 льдин.
- **Процедурное аудио:** 8 звуковых эффектов синтезируются программно при старте через `AudioStreamWAV`.

## Управление

| Клавиша / Действие | Назначение |
|---|---|
| `WASD` / Стрелки / Зажатие `ЛКМ` | Передвижение героя (под 45° изометрию) |
| `ЛКМ` в главном меню | Разбивание плывущих льдин по клику |
| `Esc` | Открыть / закрыть меню паузы |
| `R` | Перезапуск игры |
| `F11` | Полноэкранный режим |
| `V` | Переключить камеру от первого лица (свободный осмотр + добыча по ЛКМ) |
| `F1` / `` ` `` | Открыть / закрыть чит-меню для тестирования |

## Запуск проекта

1. Установите **Godot Engine 4.7.2** (или новее в ветке 4.x, Forward+).
2. Откройте файл `project.godot` через Godot Project Manager.
3. Запустите главную сцену `res://scenes/main.tscn` (`F5`).
